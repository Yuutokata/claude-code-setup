# Skills

This repo does not ship skill files. The skills I run day to day are third-party work, and I only redistribute what I wrote myself. Install the ones you want from their upstream projects, and keep their licenses.

## What I use

- **Engineering workflow:** `tdd`, `diagnosing-bugs`, `code-review`, `codebase-design`, `improve-codebase-architecture`, `domain-modeling`, `prototype`, `research`, `resolving-merge-conflicts`, `thermo-nuclear-code-quality-review`
- **Spec to implementation:** `to-spec`, `to-tickets`, `triage`, `wayfinder`, `implement`, `implement-spec`, `to-questionnaire`, `setup-matt-pocock-skills`
- **Hand-off and interviews:** `handoff`, `claude-handoff`, `grilling`, `grill-me`, `grill-with-docs`
- **Frontend:** `impeccable`, `responsive-design`, `vite`, `web-perf`, `design-md`
- **Tooling:** `git-guardrails-claude-code`, `setup-pre-commit`, `find-skills`, `wizard`, `writing-for-agents`
